# Starting9

プロ野球のスタメンを予想し、発表後に自動採点するWebアプリです。

## 概要

Starting9 は、プロ野球ファン向けのスタメン予想ゲームです。

ユーザーは試合開始前に、1〜9番の打順・守備位置・選手を予想します。  
実際のスタメン発表後、予想内容と実スタメンを照合し、選手・打順・守備位置の一致度に応じてスコアを算出します。

X上で行われているスタメン予想文化を、採点・ランキング・共有までできるWebゲームとして再構成することを目的としています。

## 制作背景

プロ野球ファンの間では、試合前に「今日のスタメンはどうなるか」を予想する文化があります。

しかし、X上での予想は投稿ごとに分散しており、以下のような課題があります。

- 予想を一覧で確認しづらい
- 発表後に自動で採点できない
- 他の参加者とスコアを比較しづらい
- 結果を共有しにくい

Starting9 は、こうした予想文化をゲーム化し、試合前後の楽しみを広げることを目指しています。

## 採点ルール

1人につき最大3点で採点します。

| 項目 | 点数 |
|---|---:|
| 選手がスタメン入り | 1点 |
| 打順が一致 | 1点 |
| 守備位置が一致 | 1点 |

9人 × 3点で、最大27点です。

## データ取得方針

本アプリは、プロ野球ファン向けのスタメン予想ゲームです。

掲載されるスタメン・試合情報は、発表済みの情報をもとに、予想結果の採点・ランキング表示を目的として独自に整理する予定です。

公式記録・公式発表の代替を目的としたものではありません。  
正確なスタメン、試合結果、選手成績などの最終的な情報については、NPB公式サイトおよび各球団公式発表をご確認ください。

初期版では、実スタメンの登録は管理者確認を挟む方式を採用し、外部情報の取得結果を直接公開データとして反映しない設計を目指しています。
