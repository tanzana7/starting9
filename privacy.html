PRIVACY POLICY

プライバシーポリシー

Starting9における情報の取り扱いについて案内します。

← トップへ戻る

1. 取得する情報

  • アカウント登録・ログインに必要な情報（ユーザー名、認証情報）
  • 表示名として利用するユーザー名、保存した予想内容、採点結果
  • ランキング表示に必要な成績・参加状況
  • アクセス時の日時、ブラウザ、端末、ネットワーク等の技術情報

取得する情報は、サービス提供に必要な範囲に限るよう努めます。パスワードそのものを画面やランキングに表示することはありません。

2. 利用目的

  • ログイン状態やアカウントを管理するため
  • 予想を保存し、採点結果や過去の成績を表示するため
  • ランキングや実績を表示するため
  • 不正利用、攻撃、過度な負荷等を防ぐため
  • サービスの不具合確認・改善を行うため

3. 第三者提供

法令等に基づく場合を除き、取得した情報を第三者へ販売・提供することはありません。サービス運営に必要な範囲で、下記の外部サービスを利用する場合があります。

4. 外部サービスと外部リンク

サービスの配信、認証、データ保存にはCloudflare Pages、Cloudflare Workers、Cloudflare D1等を利用しています。これらの基盤では、サービス提供に必要なログや技術情報が処理される場合があります。

選手成績の確認などのため、NPBase等の外部サイトへのリンクを掲載する場合があります。外部サイトの利用や情報の取り扱いは、各サイトの方針をご確認ください。Starting9が外部サイトのデータを転載・収集・保存するものではありません。

5. Cloudflare Web Analytics

公開ページのアクセス数、ページビュー、流入元などの利用状況を把握するため、Cloudflare Web Analyticsを利用します。

Cloudflare Web AnalyticsのCookieを使用しない公式の計測方式を利用し、Starting9からユーザー名、メールアドレス、アカウントID、予想内容、認証情報、トークンを独自に送信しません。詳細はCloudflare Web Analyticsの説明およびCloudflareのプライバシーポリシーをご確認ください。

6. Cookieと認証セッション

ログイン状態を維持するため、認証セッションに関するCookie等を利用する場合があります。ブラウザの設定でCookieを制限すると、ログインや予想保存の一部が利用できないことがあります。

7. 保管と安全管理

取得した情報は、利用目的に必要な期間・範囲で取り扱います。個人開発のβ版として、合理的な安全管理に努めますが、インターネット上の情報送信について完全な安全を保証するものではありません。

8. 問い合わせと改定

情報の取り扱いに関する問い合わせは問い合わせページからご連絡ください。本ポリシーは、サービス内容や法令等に応じて改定する場合があります。
