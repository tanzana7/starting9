# Starting9

プロ野球のスタメンを予想し、発表後に採点して楽しむWebアプリです。

現在は北海道日本ハムファイターズ専用の個人開発MVPとして実装しています。  
ログイン、データベース、ランキング、全12球団対応はまだ行わず、静的Webアプリとして主要な体験検証に集中しています。

## 概要

Starting9 は、試合前に1〜9番の打順・守備位置・選手を予想し、実際のスタメン発表後に一致度を100点満点で採点するスタメン予想ゲームです。

Xなどで行われている「今日のスタメン予想」文化を、入力・採点・結果表示・共有までできるWeb体験として再構成することを目的としています。

## 制作背景

プロ野球ファンの間では、試合前にスタメンを予想して楽しむ文化があります。

一方で、SNS上の投稿だけでは以下のような課題があります。

- 予想内容が投稿ごとに分散する
- 実際のスタメン発表後に採点しづらい
- 打順や守備位置まで含めた一致度を比較しにくい
- 結果をゲームとして振り返りにくい

Starting9 は、この試合前後の楽しみをWebアプリとして整理し、将来的にランキングや共有機能へ拡張できる土台を作るためのMVPです。

## 採点ルール

100点満点方式で採点します。

| カテゴリ | ルール | 最大点 |
|---|---|---:|
| 出場的中 | 予想した選手が実スタメンに出場していた場合、1人5点。9人全員的中で+5点 | 50点 |
| 打順的中 | 予想した選手の打順が一致していた場合、1人3点。9人全員的中で+3点 | 30点 |
| 守備位置的中 | 予想した選手の守備位置が一致していた場合、1人2点。9人全員的中で+2点 | 20点 |

合計は最大100点です。  
各カテゴリのパーフェクトボーナスはカテゴリ内にのみ加算し、100点を超えない設計にしています。

## データ取得方針

実スタメンは、NPB公式試合ページを確認元とした候補取得に対応しています。

ブラウザからNPB公式ページを直接取得するとCORS制限を受ける可能性があるため、Cloudflare Workerを中継APIとして利用しています。Workerは対象ページを取得し、「最新のオーダー」周辺から日本ハム側の候補スタメンを抽出してJSONで返します。

取得した情報は、即時に正式な実スタメンとして登録しません。  
管理者用エリアで候補プレビューを表示し、内容確認後に「承認して実スタメンに登録」することで、初めて採点用データとして利用します。

本アプリは公式記録・公式発表の代替を目的としたものではありません。  
正確なスタメン、試合結果、選手成績などの最終的な情報については、NPB公式サイトおよび各球団公式発表をご確認ください。

## Worker API

Cloudflare Workerのソースコードは、リポジトリ内の `cloudflare-worker.js` で管理しています。

リクエスト例:

```text
https://<worker-url>/?url=https://npb.jp/scores/2026/0707/m-f-12/
```

成功時のレスポンス例:

```json
{
  "ok": true,
  "sourceUrl": "https://npb.jp/scores/2026/0707/m-f-12/",
  "lineupText": "1 遊 大塚瑠晏\n2 一 清宮幸太郎\n3 指 レイエス"
}
```

抽出失敗時は、`debug=1` を付けることで調査用のテキスト抜粋を返します。

```text
https://<worker-url>/?url=https://npb.jp/scores/2026/0707/m-f-12/&debug=1
```

## 開発目的

本プロジェクトは、個人開発およびポートフォリオ用途を想定したMVPです。

単に画面を作るだけでなく、以下の観点を意識して開発しています。

- 既存のファン文化をWebサービス化する企画設計
- MVPから段階的に拡張する開発方針
- 入力体験、管理者承認、採点結果表示まで含めたUX設計
- 外部ページを確認元とした候補取得と、手動承認を挟む安全な運用設計
- 静的アプリからWorker、将来的なDB連携へ拡張できる構成
